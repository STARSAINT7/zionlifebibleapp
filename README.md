📖 ZIONLIFE Holy Bible KJV
ZIONLIFE Holy Bible KJV is a meticulously crafted, lightweight, and immersive single-page web application designed to provide seamless 24/7 access to the King James Version (KJV) of the Holy Bible. Built with elegance and performance in mind, it provides a distration-free digital reading experience optimized for both desktop and mobile devices.

✨ Key Features
Instant Full-Text Search: Search the scriptures dynamically with real-time keyword matching and highlighted result previews.

Dynamic Theme Engine: Switch instantly between custom light/dark modes and a rich palette of premium visual themes (Royal, Emerald, Crimson, Ocean, Rose Gold, and more).

Advanced Reading Controls: Easily adjust font sizes (A- / A+) and utilize smooth chapter-by-chapter navigation.

Verse Bookmarking & Management: Save, organize, and revisit your favorite verses anytime using the built-in bookmarks panel.

Quick Copy & Share: Copy verses directly to your clipboard with a single click, complete with instant toast feedback notifications.

Fully Responsive Design: Tailored layout featuring touch-friendly navigation, seamless mobile viewport scaling, and distraction-free fullscreen support.

🛠️ Built With
HTML5 – Semantic structure and layout architecture.

Vanilla JavaScript (ES6+) – Interactive state management, search engine logic, and local storage persistence.

CSS3 / Custom Properties – Advanced glassmorphism styling, dynamic color themes, and media queries.

Google Fonts – Featuring Cinzel, Cormorant Garamond, and EB Garamond for a classic, elegant typographic feel.
